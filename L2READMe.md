# Personal Portfolio Website (CSS Core)

## About
This is my personal portfolio website created using HTML and CSS as part of my Web Development Lab Assignment 2.

## Features
- About Me section with a profile picture.
- Navigation bar with links to different sections.
- Technical Skills table.
- Projects section with project details.
- Contact form with Name, Email and Message fields.
- Consistent color theme and fonts.
- Hover effects on navigation links and buttons.
- Back to Top button.
- Proper spacing using margin and padding.
- Styled borders and shadows.

## Technologies Used
- HTML
- CSS
